# 04: Benchmark transcription on the A50

**What to build:** Measure end-to-end dictation performance on the Samsung A50: record several short English messages, time transcription vs. audio length, and note qualitative accuracy. Compare `base`, `small`, and `tiny` to pick the A50's default, and record the result so the model choice is decided with data.

**Status:** ready-for-agent

- [ ] Qualitative accuracy captured for base/small/tiny (at least a couple test phrases each)
- [ ] A default model size is chosen and recorded with the benchmark results
